FONADHOO MAP — EDITABLE HOUSE NAMES

Upload all files to the root of the GitHub repository.

EDIT A NAMED HOUSE
1. Open houses.json on GitHub.
2. Find the house, for example "Blue Bell".
3. Rename the JSON key to the new house name, for example "kercs". Keep its position in the file unchanged.
4. Commit the change and refresh the live map.
5. The map uses the new name and search finds the new name.

You can also add a "houseName" field inside a house record. That value overrides the displayed/searchable name.

Other fields remain editable: houseNumber, area, feederNumber, distributionBox, breakerNumber, meterNumber.
